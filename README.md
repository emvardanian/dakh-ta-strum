# Дах та струм — прототипи сайту

Три варіанти сайту для компанії «Дах та струм» (покрівля, фасади, металоконструкції, електромонтаж).

- `/` — сторінка для обговорення: варіанти, портрет клієнта, що уточнити
- `/a/` — варіант A «Класика phservs»
- `/b/` — варіант B «Графіт»
- `/c/` — варіант C «Фірмовий синій»

Спільний код: `assets/core.js` (шапка-рілс, портфоліо, каталог, квіз), дані: `assets/works.js`, `assets/catalog.js`.
Заявки: підставте адресу обробника в `FORM_ENDPOINT` у `assets/core.js`.
